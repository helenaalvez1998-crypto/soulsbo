# Cópia dos prompts e referência visual

O botão do Ateliê executa duas ações ao mesmo tempo:
1. Copia para a área de transferência o texto completo da Análise artística (PT) e do Prompt fixo.
2. Baixa a imagem PNG da facção selecionada.

A imagem é baixada separadamente porque não há garantia de que o aplicativo de destino aceite a representação de imagem de uma área de transferência que também contém texto. Para usar o pacote na IA, cole os prompts e anexe o PNG baixado.
