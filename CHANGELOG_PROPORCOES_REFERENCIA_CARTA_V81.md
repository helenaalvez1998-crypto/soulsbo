# V81 — Fidelidade às proporções da carta de referência

- Adicionada ao prompt mestre uma regra explícita para preservar as proporções relativas dos elementos de uma carta completa de referência.
- A regra cobre moldura, janela da ilustração, cabeçalho, título, banner da facção, tipo de combate, ícones, indicadores de poder e painéis de habilidade, lore e sinergia.
- Proíbe ampliar, reduzir, esticar, comprimir, cortar, reorganizar ou redesenhar elementos isoladamente.
- A regra só se aplica quando uma referência de carta completa/layout é fornecida. Sem essa referência, mantém-se a saída de ilustração isolada, sem moldura ou interface.
- Mantida a especificação 5:4 já existente para a ilustração gerada; a nova regra trata das proporções relativas dos elementos, não substitui o formato de saída.
